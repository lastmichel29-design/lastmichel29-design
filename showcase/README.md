# AXYOM Public Showcase

AXYOM is an independent R&D project focused on controlled, testable and evidence-oriented AI-agent systems.

This public showcase intentionally exposes only sanitized documentation and selected engineering evidence. It does **not** contain the private AXYOM runtime, credentials, private datasets, internal prompts or proprietary implementation details.

## Focus areas

- AI-agent evaluation
- Python and PowerShell automation
- Windows UI Automation
- Computer-use experimentation
- Local / offline AI
- Context-efficient agent workflows
- Repository auditing
- SHA-256 evidence and manifests
- Fail-closed validation
- Reproducible technical reporting

## Engineering rule

> Execution is not equivalent to verification.

AXYOM separates:

```text
claim → execution → observation → verification → evidence
```
