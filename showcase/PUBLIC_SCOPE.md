# AXYOM Public / Private Boundary

## Public

- sanitized architecture descriptions
- selected case studies
- public capability summaries
- public hashes and evidence summaries
- portfolio material

## Private

- AXYOM core implementation
- private runtime source
- credentials and API keys
- private datasets
- unpublished algorithms
- internal prompts
- private evaluation material
- proprietary implementation details

A public repository can be copied or cloned. AXYOM protects its implementation by publishing only material intentionally safe to disclose.
