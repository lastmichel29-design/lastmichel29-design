AXYOM Agent Judge

Deterministic classification of a claim and its evidence package, computed locally in your browser. No LLM, no external API or model network requests, no private runtime.

Public explanation

AXYOM Agent Judge does not determine absolute truth. It classifies the evidence state of a claim according to explicit deterministic rules.

  • Artifact existence is not claim truth.
  • A hash match is not authorship.
  • A hash match is not meaning.
  • A passing test is not universal correctness.
  • Execution is not verification.
  • Verification is not absolute truth.
  • Independent reproduction is stronger evidence than a single local run.

    Fail-closed boundaries

    • The judge classifies evidence state; it never asserts absolute truth.
    • VERIFIED_ARTIFACT means two valid SHA-256 digests matched exactly — not authorship, not meaning, not truth.
    • TEST_RESULT is classified as evidence, never as proof.
    • Unrecognized or missing input fails closed to UNKNOWN or INSUFFICIENT_EVIDENCE.
    • Nothing is sent anywhere; classification runs in this browser.
    • This public demo is not the private AXYOM runtime.

    Epistemic boundaries

    • A SHA-256 hash demonstrates byte identity, not truth.
    • PASS for the known vectors certifies only the tests implemented on this page. It is not a general security guarantee.
    • This public demo is not the private AXYOM runtime.
    • This is not a production security certification.
    • No claim of absolute security.
    • No claim of human-level autonomy.

    Scope of this demo

    Verification-first

    Claims, execution, observation, verification and evidence are treated as different states.

    Public / private boundary

    This demo contains only sanitized material. It does not expose the private AXYOM implementation.

    Fail-closed

    If the public corpus does not support an answer, the demo says so instead of inventing one.
